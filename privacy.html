Datenschutz

Buffln — Vokabeltrainer für Latein, Französisch und Englisch. Stand: 3. November 2026.

Kurzfassung

Buffln braucht kein Konto, sammelt keine Namen, keine E-Mail-Adressen und kein Nutzungsverhalten zu Werbezwecken. Der Lernfortschritt liegt auf dem Gerät.

Was auf dem Gerät gespeichert wird

  • Lernfortschritt pro Fach (Boxen, Fälligkeiten, richtige und falsche Antworten), Prüfungsnotizen und eigene Wörter.
  • Einstellungen (Modus, Stimme, Richtung, Prüfungslänge).

Diese Daten verlassen das Gerät nur, wenn du die Synchronisation selbst einschaltest.

Synchronisation (optional)

Für den Abgleich zwischen iPhone und Computer erzeugt die App einen Code. Aus diesem Code wird auf dem Gerät ein Schlüssel berechnet, und der Lernstand wird vor dem Senden verschlüsselt (AES-GCM). Der Server speichert nur einen aus dem Code abgeleiteten Bezeichner und den verschlüsselten Block — er kann keine Wörter, Bedeutungen oder Namen lesen. Wer den Code nicht kennt, kann die Daten nicht entschlüsseln. Der Server steht bei Cloudflare (Workers + D1).

Foto-Import (optional)

Der Foto-Import liest Vokabeln aus einem Bild. Standardmässig passiert das auf dem Gerät, nur wenn du „Mit KI genauer lesen" auswählst, verlässt das Bild den Dienst Buffalo (Cloudflare Worker). Er schickt es an ein Sprachmodell zur Auswertung, speichert es nicht und gibt nur Wort-Paare zurück. Ohne diese Auswahl verlässt kein Bild das Gerät.

Aussprache

Die Hörbeispiele sind vorproduzierte Audiodateien und liegen in der App. Für das Abspielen wird keine Verbindung zu einem Sprachdienst aufgebaut.

Kein Tracking

Keine Analyse-SDKs, keine Werbung, keine Weitergabe an Dritte. Die App erklärt das auch gegenüber Apple im Privacy Manifest (NSPrivacyTracking: false).

Kinder

Die App ist für den Schulunterricht gedacht und enthält keine Chats, keine Werbung und keine Käufe, die eine elterliche Freigabe erfordern.

Löschen

Einstellungen → „Fortschritt zurücksetzen" löscht die Lernstände auf dem Gerät. Wer zusätzlich die Kopie auf dem Sync-Server löschen will, schickt eine kurze Nachricht an die unten stehende Adresse; ohne den Code ist der Block nicht lesbar und wird auf Wunsch gelöscht.
